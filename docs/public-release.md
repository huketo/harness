# 공개 배포 정책

[문서 색인](index.md) · [English README](../README.md) · [한국어 README](../README.ko.md) · [MIT 라이선스](../LICENSE)

이 문서는 Harness 공개본을 만들고 유지할 때 적용하는 정책입니다. 현재 저장소의 공개 여부나 특정 배포가 이미 완료되었다고 주장하지 않습니다.

## 배포 범위

- 공개본은 정제된 소스에서 **새 초기 이력**으로 시작합니다. 이전 개발 이력, 비공개 이슈, 운영 자료, 로컬 감사 기록은 공개 이력의 출처나 첨부물로 사용하지 않습니다.
- Harness 자체 코드는 루트 [MIT 라이선스](../LICENSE)로 배포합니다. 서드파티·편입 구성요소의 원저작자 고지와 별도 라이선스는 유지합니다.
- 유지하는 환경은 Linux/WSL2, OMP 18.1.13, Bun 1.3.14입니다. 다른 운영체제나 버전의 호환성을 약속하지 않습니다.
- 배포 스냅샷은 검토용 예시입니다. 개인 호스트 설정을 자동으로 복사하지 않으며, cron 스냅샷에는 예약 작업을 배포하지 않습니다.
- 공개 의존성만 남깁니다. 설치에 필요한 외부 프로젝트의 접근성, 출처, 라이선스 고지를 배포 후보에서 확인합니다.

## 공개 데이터 경계

커밋에는 자격증명, 개인 이메일, 비공개 URL, 절대 홈 경로, 실제 업무·보고 내용, 개인 식별자, 세션·로그·데이터베이스, 원격 이슈 사본, 로컬 감사 입력과 원시 벤치마크 실행 데이터를 넣지 않습니다. 예제와 fixture는 처음부터 합성 자료로 작성하며 실제 자료를 합성 자료로 이름만 바꾸지 않습니다.

`var/`는 로컬 생성물 경로이며 공개 산출물이 아닙니다. `.gitignore`는 비밀 검사가 아니므로 배포 후보의 추적 파일과 새 초기 이력을 별도로 검토합니다.

## 프로젝트 운영 정책

이 저장소는 소유자만 유지하는 개인 쇼케이스입니다. 버그 제보, 기능 요청, issue, pull request, 외부 기여, 지원 요청, 취약점 제보를 받지 않습니다. 재사용자는 MIT 라이선스에 따라 fork를 독립적으로 유지합니다. Issues, pull requests, Discussions, Private Vulnerability Reporting을 협업이나 연락 채널로 제공하지 않습니다.

일일보고 기능은 공개 [GitLab](https://gitlab.com)과 `glab`, 기존 iCal/`khal` 수집기를 사용해 근거 있는 초안을 만드는 개인 워크플로입니다. 사용자가 초안을 검토한 뒤 자신의 [Daou Office](https://daouoffice.com) tenant UI에 직접 입력하고 제출합니다. Harness는 Daou Office CLI, API, 인증 경로, 자동 제출 기능을 제공한다고 주장하지 않습니다.

## 배포 전 소유자 점검

배포하는 정확한 트리에서 다음 불변식을 확인합니다.

1. 루트 라이선스와 외부 구성요소 고지가 함께 존재한다.
2. 지원 환경과 설치 부작용이 README와 설치 안내에서 일치한다.
3. 추적 파일과 초기 이력에 공개 데이터 경계를 넘는 값이 없다.
4. cron 스냅샷은 비어 있고 예시 설정은 개인 호스트 상태를 복원하지 않는다.
5. 제거한 보고 runner·내부 corpus·비공개 의존성을 가리키는 문서나 명령이 없다.
6. 원격의 협업·지원·취약점 제보 기능이 이 프로젝트 정책과 일치한다.

공개 후에도 같은 경계를 적용합니다. 소유자는 저장소를 계속 갱신할 수 있지만, 호스트에서 새로 수집한 스냅샷이나 실행 산출물을 검토 없이 반영하지 않습니다.
