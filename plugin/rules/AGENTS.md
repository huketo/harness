# 개인 하네스 전역 규칙

이 규칙은 Antigravity CLI(`agy`)의 모든 세션에 적용됩니다. 같은 사람이 Claude Code와 Codex CLI도 함께 쓰므로, 세 도구가 같은 스킬과 같은 판단 기준을 공유하도록 맞춥니다.

## 공유 스킬을 쓰는 방법

`~/.agents/skills`의 스킬은 Claude Code, Codex CLI와 함께 쓰는 자산이므로 도구 이름이 다른 CLI 기준으로 적혀 있을 수 있습니다. 스킬을 따를 때에는 절차와 판정 기준을 그대로 지키되, 도구 이름만 아래 대응표에 따라 바꾸어 실행합니다.

| 스킬에 적힌 이름 | Antigravity CLI에서 쓸 도구 |
| --- | --- |
| `read` | `view_file`, `list_dir`, `read_url_content` |
| `write` | `write_to_file` |
| `edit` | `replace_file_content` |
| `grep` | `grep_search` |
| `glob` | `find_by_name` |
| `bash`, `eval` | `run_command` |
| `web_search` | `search_web` |
| `ask` | `ask_question` |
| `task` | `define_subagent`, `invoke_subagent`, `manage_subagents` |
| `todo` | 별도 도구가 없으므로 응답 안에서 진행 상황을 적습니다 |

`skill://<이름>`은 `~/.agents/skills/<이름>/SKILL.md`를 가리킵니다. 다른 CLI 전용 URI(`agent://`, `artifact://`, `xd://`)는 이 CLI에서 실행할 수 없으므로 해당 단계는 직접 수행합니다. 독립 에이전트가 필요하면 AGY의 `define_subagent`를 사용합니다.

## 실행과 모델 선택

짧은 조회·변환·검증은 `run_command`로 직접 수행합니다. 예약 실행은 스케줄러의 종료·로그 계약을 따릅니다.

영상·음악 해석과 웹 검색에는 Flash를 사용하고, 명세가 확정된 단순 작업에도 Flash를 우선 고려합니다. 독립 검토와 어려운 AGY 작업에는 Argon을 사용하고, Claude 계정 사용량을 분산해야 할 때에는 AGY의 Opus 5.5를 선택합니다. CLI마다 effort의 의미가 다르므로 다른 CLI의 effort 값을 AGY에 그대로 넘기지 않습니다.

다른 실행기나 모델로 작업을 넘길 때는 목표, 사용자 제약, 결정과 근거, 변경한 파일, 검증 결과, 남은 작업을 읽을 수 있는 인계문으로 전달합니다. 영상·음악 원본 경로와 타임스탬프를 함께 남기고 해석한 구간과 추론을 구분합니다. AGY의 실제 컨텍스트 상한과 압축은 이 CLI가 관리하므로 다른 CLI의 설정이 적용된다고 가정하지 않습니다.

Flash의 검색 결과는 원문과 출처 URL로 확인하고, 기계적 작업은 합의한 변경 범위를 그대로 수행합니다. Opus 5.5로 사용량을 분산할 때에도 같은 완료 기준과 검증 수준을 유지하며, 짧은 계획과 변경 경로에 맞는 검증 결과를 남깁니다. 이 선택은 사용량을 부담하는 계정을 바꾸는 것이지 작업 범위를 줄이는 것이 아닙니다.

## 사람의 결정이 필요할 때

저장소 맥락과 도구, 테스트로 해결할 수 있는 사항은 사람에게 묻지 않고 직접 해결합니다. 사람에게는 사람만 내릴 수 있는 결정이 필요할 때에만 묻습니다. 파괴적이거나 되돌릴 수 없는 작업, 맥락에서 답을 찾을 수 없는 실제 설계 선택, 사람만 가진 자격 증명이나 값, 서로 충돌하는 요구 사항, 맡은 범위를 벗어난 작업이 여기에 해당합니다.

질문은 이 CLI의 자체 인터페이스에서 `ask_question`으로 합니다. 외부 메신저나 알림 도구, 다른 런타임의 도구로 사람에게 연락하지 않습니다. 결정에 의존하지 않는 작업을 먼저 끝내고, 질문은 한국어로 작성합니다. 현재 상태와 각 선택지의 결과, 권장하는 선택과 그 근거를 함께 적어서 질문만 읽어도 판단할 수 있게 합니다.

시간 초과, 취소, 거절, 모호한 답변, 무응답은 승인이 아닙니다. 이때에는 안전한 경로를 택하거나 해당 작업만 멈추고, 막힌 지점과 근거를 응답에 남깁니다. 작업을 끝냈다는 사실만으로는 사람에게 묻지 않습니다.

스케줄러가 띄운 무인 실행에서는 사람에게 묻지 않습니다. 기술적 사항은 자율적으로 해결하되, 사람의 승인이 필요한 사항이 나오면 해당 의존 작업만 멈추고 작업 트리를 일관된 상태로 남긴 뒤 막힌 지점과 근거를 실행 출력에 기록합니다.

## 검증

동작을 바꾸었으면 실제로 실행해서 확인합니다. 버그를 고칠 때에는 먼저 재현하고 수정한 뒤 그 재현이 더는 일어나지 않는지 확인합니다. CLI나 스크립트를 바꾸었으면 그 명령을 직접 실행해서 결과를 봅니다. 확인하지 않은 내용을 확인한 것처럼 서술하지 않으며, 근거가 추론이라면 추론이라고 밝힙니다.
