# 릴리스 사실 (합성 예시: 문서 편집기 Mokuji v2.4, 2026-10-21 배포)

- 댓글은 문장에 고정되며 주변 문장이 바뀌어도 위치를 유지한다.
- 모든 요금제에서 추가 비용 없이 사용할 수 있다.

- 동시 편집 인원 상한: 2명. 3명 이상은 지원하지 않는다.
- 내부 베타: 6주, 팀 12개 참여. 만족도 수치는 공개하지 않는다.
