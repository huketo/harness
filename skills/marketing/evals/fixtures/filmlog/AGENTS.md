# Filmlog agent guide

Filmlog is a Next.js web app for a Korean film-photography community. Read `docs/index.md` first and load only the documents relevant to the task.

- `app/`: the web application.
- `docs/`: product, GTM, and policy documents. Every document lists its status.
- Agent guides live in `docs/agents/`; register every new document in `docs/index.md`.
