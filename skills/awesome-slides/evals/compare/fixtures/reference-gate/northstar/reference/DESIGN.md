# 사내 보고서 디자인 규칙

## 분위기
신뢰감 있는 내부 보고서. 장식보다 숫자와 표가 먼저 보인다.

## 색
| 역할 | 값 |
| --- | --- |
| 배경 | #ffffff |
| 본문 | #1b2430 |
| 보조 글자 | #5a6675 |
| 강조 | #c2410c (주황) — 결론 숫자와 요청에만 쓴다 |
| 면 | #f1f3f5 (표 머리, 강조 상자) |

## 서체
- 제목과 본문 모두 산세리프. 제목 700, 본문 400.
- 숫자는 표 안에서 오른쪽 정렬, 고정폭 숫자.

## 배치
- 장마다 왼쪽 위에 짧은 장 번호("02")를 작게 둔다.
- 표는 가로선만 쓰고 세로선은 쓰지 않는다.
- 결론 숫자는 강조색으로 크게, 단위는 작게 붙인다.
