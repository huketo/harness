# 기술 발표 디자인 시스템 (사내 엔지니어링 블로그 기준)

## 분위기
조용하고 정확한 기술 문서처럼 보인다. 장식 대신 정렬과 여백으로 위계를 만든다.

## 색
| 역할 | 값 |
| --- | --- |
| 배경 | #f4f1e8 (종이색) |
| 본문 | #14213d (짙은 남색) |
| 보조 글자 | #5b6475 |
| 강조 | #0f766e (청록) — 한 화면에 한 가지 의미로만 쓴다 |
| 구분선 | #d9d3c3 |

## 서체
- 제목: 세리프(명조 계열), 굵기 600.
- 본문: 산세리프, 400/500.
- 코드: 고정폭, 한글 지원.

## 배치
- 제목은 항상 왼쪽 위에 맞춘다. 가운데 정렬 제목은 표지에서만 허용한다.
- 근거가 있는 장은 아래쪽에 출처 한 줄(작은 보조 글자)을 둔다.
- 모서리는 둥글리지 않는다(radius 0).
- 제목 아래에 강조색 2px 가로줄을 둔다.

## 금지
- 그라디언트, 그림자, 아이콘 장식.
