# 기존 덱 개선 요구

`crowded.html`은 Northstar라는 가상 조직의 교육용 합성 덱이다. 기존 plain HTML 엔진, 배경/본문/강조 색상과 승인 요청의 의미를 유지하면서 과밀한 내용을 읽기 좋게 개선한다. 3장을 유지할 필요는 없고 5~7장으로 나누어도 된다. 원본 fixture는 보존하고 개선본을 별도 출력한다.

보존할 내용:
- 40명, 20일/월, 6분→3분/일, 시간당 30,000원, 월 40시간·1,200,000원 환산 가치.
- 현상 유지 / SaaS / 내부 파일럿의 초기·월 비용과 장단점.
- 4주, 초기비용 3,000,000원 한도, 월 200,000원 상한.
- 검색 과제 중앙값 3분 이하, 승인되지 않은 접근 0건, 예산 상한.
- 접근권한 누출이 1건이라도 있으면 중단하고 기존 검색으로 복귀.
- 합성 가정이며 실측 ROI가 아니고, 시간 환산 가치는 현금 절감이 아니라는 제한.
- 각 원본 슬라이드의 발표자 노트 의도. 분할하면 해당 새 슬라이드의 노트로 옮긴다.

이 덱은 발표 후 PDF로 공유된다. 개선된 단일 HTML과 PDF를 제공한다. 새 프레임워크로 바꾸거나 원본 수치를 바꾸지 않는다. 입력 덱에 외부 자산은 없으며 가짜 스크린샷·로고를 추가할 필요도 없다. 실제 내용의 양과 레이아웃을 고치고 필수 내용을 CSS로 가려 해결하지 않는다.
