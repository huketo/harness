# 오프라인 발표: 네트워크가 없어도 진행되는 워크숍

6장 내외의 한국어 HTML 슬라이드를 만든다. 대상은 행사 운영자이며 교육용 체크리스트이다. 네트워크 없는 장소에서 파일 하나만 전달받아 연다. 외부 폰트, 이미지, CDN, 번들 폴더가 없어야 한다. 입력 자료는 전부 아래에 있다. 조사나 스타일 질문 없이 제작한다.

분위기: 밝은 따뜻한 배경, 짙은 글자, 주황 강조. 큰 글자와 명확한 순서를 사용한다. 산출물은 하나의 HTML과 해당 내용의 PDF이다. HTML에는 발표 화면과 좁은 화면에서 읽는 보기 전환을 제공하되, 동일한 내용을 중복 작성한 두 원본을 만들지 않는다.

필수 내용:
1. 출발 전: 최종 HTML, PDF, 발표자 연락처를 로컬에 저장한다. 연락처는 실제 개인정보 대신 현장 안내 데스크를 가리킨다.
2. 장치 확인: 전원, 화면 연결, 화면비, 소리, 키보드 이동을 점검한다.
3. 네트워크를 끄고 첫 장부터 마지막 장까지 연다. 이미 열린 화면이나 캐시만 믿지 않는다.
4. 영상에 의존하는 설명은 정지 이미지와 핵심 문장으로도 전달되도록 준비한다. 이번 덱에는 실제 영상이 없으므로 가짜 영상 재생 UI를 만들지 않는다.
5. 문제가 생기면: 원본 HTML 재열기 → PDF로 전환 → 현장 안내 데스크에 도움 요청.
6. 마지막 확인: 다음/이전 이동, 처음/마지막 장, 파일 다시 열기, 휴대폰 폭 읽기 보기.

조작 요구: 이전/다음 버튼, 좌우 방향키, 현재 장/전체 장 표시, URL fragment로 현재 장 복구. 입력란을 넣을 필요는 없다. 키보드 포커스가 숨은 슬라이드로 사라지지 않아야 한다. 브라우저 확대를 막지 않는다.

필요한 그림은 의미 있는 inline SVG 도식으로 만들 수 있다. 폰트는 한국어를 지원하는 시스템 fallback을 사용하거나 합법적으로 포함한다. 외부 링크는 안내 출처일 뿐 표시/동작에 필요한 의존성이어서는 안 된다.
