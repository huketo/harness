# 승인용 배포 자료: Northstar 문서 검색 개선

Northstar는 이 평가를 위해 만든 가상 조직이다. 아래 인원·시간·비용은 모두 교육용 합성 가정이며 고객 사례나 실측 ROI가 아니다. 실제 내부 자료는 포함하지 않는다.

## 요구

예산 승인자가 혼자 읽는 한국어 자료이다. 발표자 설명 없이 이해되어야 한다. Slidev 원본, 웹 빌드, PDF를 만들고 7~9장 정도로 정리한다. 원본 자료의 주장과 가정/제한을 보존한다. 기존 브랜드를 사용하므로 스타일 질문은 필요 없다.

브랜드: 배경 #f7f5ef, 본문 #16243a, 강조 #087e8b, 주의 #9b4d13. 한국어를 지원하는 읽기 쉬운 폰트를 사용한다. 가짜 고객 로고나 스크린샷은 만들지 않는다.

## 현재 상태와 계산 가정

- 대상 사용자 40명, 사용자당 업무일 20일/월.
- 검색에 걸리는 시간 현재 6분/일, 파일럿 목표 3분/일.
- 검토용 인건비 환산 30,000원/시간.
- 목표 달성 시 절감 시간은 월 40시간, 환산 가치는 월 1,200,000원이다.
- 이는 가용 시간의 추정 가치이며 실제 현금 절감이나 인원 감축을 의미하지 않는다.

## 비교할 대안

1. 현상 유지: 초기 0원, 월 0원. 도입 위험 없음. 검색 시간 문제를 그대로 둔다.
2. 검색 SaaS: 초기 1,000,000원, 월 600,000원. 탐색 기능을 빠르게 도입할 수 있다. 데이터 외부 전송과 공급자 의존을 검토해야 한다.
3. 내부 인덱스 파일럿: 초기 3,000,000원, 월 200,000원. 데이터 경계를 통제한다. 자체 운영과 접근권한 동기화 책임이 있다.

모든 비용은 가상 예산 가정이다. 두 도입 대안 모두 같은 3분/일 목표를 가정하며, 실제 달성률은 아직 측정되지 않았다. 파일럿을 권장하되 SaaS의 낮은 초기비용을 숨기지 않는다. ROI 계산을 넣으면 가정과 월비용 차감을 드러낸다.

## 승인 요청과 파일럿 조건

- 요청: 4주간 초기비용 한도 3,000,000원, 월 운영비 상한 200,000원의 내부 인덱스 파일럿 승인.
- 1주차: 공개 샘플 문서와 접근권한 테스트, 검색 시간 기준선 기록.
- 2주차: 제한된 참여자 대상으로 인덱스 연결, 기존 검색 유지.
- 3주차: 동일 과제 검색 시간과 잘못된 접근 허용 여부 관찰.
- 4주차: 결과 검토 후 확대 또는 철회 결정.
- 성공 기준: 비교 가능한 검색 과제에서 중앙값 시간이 3분 이하이고, 승인되지 않은 문서 접근이 0건이며, 월비용 추정이 상한 이내.
- 즉시 중단: 접근권한 누출 1건 이상. 기존 검색으로 복귀하고 인덱스 접근을 해제한다.
- 한계: 40명 전체의 실측이 아니며, 파일럿 결과와 유지보수 부담을 확인하기 전 확대하지 않는다.

필수 구성: 승인 요청, 현황/문제, 공정한 대안 비교, 가정이 보이는 계산, 일정, 위험·중단 조건, 다음 결정. 차트/표의 단위와 수치 출처를 페이지에서 찾을 수 있어야 한다.
