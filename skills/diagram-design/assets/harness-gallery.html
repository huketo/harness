3. 검증 범위와 실측 결과

2026-09-10, Linux headless Chrome 150.0.7871.24에서 확인했습니다. 네 다이어그램에 동일한 조건을 적용했습니다.

  • 360px 독립 HTML: SVG 폭 336px, 최소 글자 12.60px.
  • 360px Slate 문서 삽입: SVG 폭 309.22px, 최소 글자 11.60px.
  • 1280px 독립 HTML·문서 삽입: SVG 폭 520px, 최소 글자 19.50px.
  • 초기 검수의 “겹침 0건”은 글자끼리의 겹침과 캔버스 잘림에 한정됐으며, 소속 박스 넘침과 연결선 충돌을 놓쳤습니다. 보안 경계·병목 예시의 당시 통과 판정은 철회하고 수정 후 다시 검증했습니다.
  • 수정된 보안 경계 19개·병목 31개 텍스트를 각각 소속 박스에 연결해 전수 검사했습니다. 360px·1280px의 독립 HTML과 문서 삽입 모두에서 소속 누락, 박스 여백 미달, 텍스트·연결선 충돌, 화살표 라벨 간격 미달이 0건입니다. 연결선 10개와 화살표 라벨 5개를 검사했습니다. 이 강화 검수 결과는 해당 두 수정본에만 적용됩니다.
  • 두 수정본의 주석 마스크 15개는 테두리를 없애고 바로 뒤 캔버스·그룹과 같은 불투명 배경색을 사용합니다. 실제 노드·영역의 테두리는 유지하며, 360px·1280px 독립 HTML과 문서 삽입에서 배경색 일치 및 기존 간격을 확인했습니다.
  • 타임라인 0·30·75·120·150분의 위치는 y=64+2.4×분을 만족합니다. 경계 차단과 호출·응답, 병목 처리율과 대기열 점유는 시각 검토로 구분했습니다.
  • Word 파일에 네 PNG가 원본 바이트 그대로 포함되는 것까지 확인했습니다. 실제 Word 앱 렌더는 검증하지 않았습니다.
