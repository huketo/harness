# GPT Image 2.5 프롬프팅 원칙

출처: [OpenAI Image prompting guide](https://developers.openai.com/api/docs/guides/image-prompting?model=gpt-image-2.5). 확인일 2026-09-09. 다음은 프롬프트 설계 기준이며 현재 네이티브 런타임이 특정 이미지 모델이나 API 옵션을 지원한다는 보장이 아니다.

## 생성과 편집

생성은 목적·장면·구도·시각 언어를 구체적으로 적는다. JSON이나 태그 같은 특별 문법보다 읽고 수정할 수 있는 자연어를 우선한다. 사진의 자연스러움을 원하면 실제 재질·빛·시점으로 설명하고 과장된 영화 조명을 자동으로 덧붙이지 않는다.

편집은 변경할 것과 보존할 것을 나눈다. 여러 입력에는 역할을 지정한다. 스타일 참조는 팔레트·질감·매체를 가져오되 원본 인물이나 물체를 자동으로 가져오지 않는다. 캐릭터 연속 장면은 기준 이미지를 재사용하고 외형·비율·의상의 핵심을 반복한다.

정확한 문구는 인용하고 위치·횟수·가독성을 지정한다. 한국어 제목을 넣을 때 문장 전체를 과도하게 길게 하지 않고, 긴 본문이 필수면 글자 영역을 충분히 확보하거나 후처리 타이포그래피를 사용한다. 후처리했다면 생성 모델이 그 글자를 정확히 그렸다고 주장하지 않는다.

한 번 생성해 확인한 뒤 한 조건씩 바꾼다. 편집 시에도 원치 않는 변화와 문자 오류를 다시 검사한다. 픽셀 보존과 정확한 도식 관계는 생성 모델의 보장으로 표현하지 않는다.

## 공식 API 설정과 네이티브의 차이

가이드는 속도가 중요한 출발점으로 `gpt-image-2.5-flare`, 까다로운 품질 요구에 `gpt-image-2.5-sunburst`를 제시한다. 같은 프롬프트·입력·크기·명시적 품질로 평가하고, 같은 quality 이름이 모델 간 같은 품질·시간을 뜻한다고 가정하지 않는다.

공식 2.5 설정은 `quality=auto|low|medium|high|xhigh|max`, `background=auto|opaque|transparent`, `size=auto` 또는 지원 크기를 포함한다. 커스텀 크기는 각 변 16의 배수, 각 변 최대 3840, 긴 변/짧은 변 최대 3, 총 픽셀 655360~8294400이다. 총 3686400픽셀 초과는 실험적이다. 실행 시점의 공식 문서와 선택 모델 지원을 다시 확인한다.

이 설정을 OMP/Codex/AGY 도구에 그대로 붙이지 않는다. 현재 도구가 노출한 옵션만 전달하고, 정확한 옵션 제어가 필요한데 네이티브가 지원하지 않으면 그 차이를 알린다.

투명 배경은 프롬프트뿐 아니라 지원되는 background 설정, PNG/WebP 같은 알파 지원 형식이 필요하다. PNG에는 JPEG/WebP용 compression 옵션을 붙이지 않는다. 네이티브가 투명 출력 옵션을 제공하지 않으면 생성 명령만으로 실제 투명도를 보장하지 않는다. 결과의 알파와 가장자리를 검사한다.

가이드 하단의 runnable Python 예제는 `gpt-image-2`에 고정되어 있다. 예제를 복사해 2.5 실행이라고 보고하지 않는다. 실제 출처는 도구 응답과 [C2PA](provenance.md)로 확인한다.
