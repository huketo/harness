# 일일 업무보고 문체 가이드

이 문서의 예시는 모두 합성 자료다. 실제 사람, 조직, 프로젝트, 보고서에서 가져온 문장을 사용하지 않는다.

## 오늘 한 일

### 주제별로 묶기

연관된 커밋을 한 주제 아래 묶으면 작업의 목적이 드러난다.

좋은 합성 예시:

```text
검색 품질 개선
  날짜 필터의 시간대 경계 수정 (a1b2c3d)
  빈 결과 안내 문구와 API 예제 갱신 (e4f5a6b)
배포 도구 정리
  설정 검사 오류 메시지 개선 (c7d8e9f)
```

피할 예시:

```text
- a1b2c3d fix: timezone
- e4f5a6b docs: update examples
- c7d8e9f chore: improve error
```

영문 커밋 제목을 그대로 붙이지 말고, 확인된 변경을 자연스러운 한국어로 요약한다.

### 항목 형식

- leaf 항목은 `수정`, `추가`, `작성`, `정리`, `검토`, `확인` 같은 명사형으로 끝낸다.
- 커밋 근거가 있으면 끝에 7자 short SHA를 붙인다: `(a1b2c3d)`.
- 한 항목이 여러 커밋에 걸치면 필요한 SHA만 쉼표로 구분한다.
- MR 활동은 프로젝트가 하나일 때 `MR #42`, 여러 프로젝트일 때 `example/atlas!42`처럼 출처를 구분한다.
- 커밋 제목이나 MR 제목에서 확인할 수 없는 성과, 수치, 완료 상태를 덧붙이지 않는다.

### 회의와 일정

캘린더 항목은 커밋이 아니므로 SHA를 붙이지 않는다.

```text
주간 동기화 회의 참석
회의
  릴리스 범위 검토
  접근성 점검 결과 공유
  다음 반복 주기 계획 논의
외부 워크숍 2일차 참석
```

- 회의가 1–2건이면 최상위 항목으로, 3건 이상이면 `회의` 아래 묶는다.
- 여러 날 일정은 `2일차`처럼 진행 일수를 표시한다.
- 휴가와 반차는 커밋이 적은 이유를 설명하므로 앞에 둔다.
- 개인 캘린더 일정은 보고서에 넣지 않는다.
- 참석 여부가 불명확한 초대는 사용자가 확인하기 전까지 초안에 확정적으로 쓰지 않는다.

## 다음 계획

계획은 확정 일정, 진행 중 이슈, 우선순위 높은 이슈 순으로 3–6개를 고른다.

```text
주간 동기화 회의 후속 결정 정리
example/atlas#123 페이지네이션 경계 처리
공개 API 문서 예제 검토
배포 체크리스트 갱신
```

- 한 줄에 한 행동을 적고 구체적인 대상을 포함한다.
- 계획에는 SHA를 붙이지 않는다.
- `추가 작업`, `기타 작업`처럼 검증할 수 없는 표현은 구체화한다.
- 오늘 완료한 항목은 다음 계획에서 뺀다.
- 계획 근거가 없으면 사용자에게 묻고 만들어 내지 않는다.

## 선택 항목

차단 요소, 제안, 비고 같은 선택 필드는 사용자가 현재 Daou Office 테넌트 양식에서 확인한 경우에만 작성한다.

- 차단 요소: 진행을 막는 실제 의존성이나 응답 대기
- 제안: 검토가 필요한 구체적 변경안
- 비고: 그날 결정된 사항이나 다음 작업에 필요한 짧은 맥락

합성 예시:

```text
비고: 검색 API의 날짜 경계는 Asia/Seoul 기준으로 통일하기로 결정.
```

## HTML이 필요한 양식

사용자가 자신의 테넌트 양식에서 HTML 입력이 필요하다고 확인한 경우에만 목록을 변환한다.

```html
<ul>
  <li>검색 품질 개선
    <ul>
      <li>날짜 필터의 시간대 경계 수정 (a1b2c3d)</li>
    </ul>
  </li>
  <li>주간 동기화 회의 참석</li>
</ul>
```

외부 문자열은 HTML 이스케이프한다.

- `&` → `&amp;`
- `<` → `&lt;`
- `>` → `&gt;`
- 목록 구조는 `<ul>`과 `<li>`로 표현한다.

Daou Office의 필드명, 저장 형식, 제출 동작은 테넌트마다 다를 수 있다. 현재 화면과 테넌트 도움말을 기준으로 하고 이 저장소에 없는 규칙을 추측하지 않는다.
