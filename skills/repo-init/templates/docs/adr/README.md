# Architecture decision records

Each file records one decision as `NNNN-slug.md`, numbered from `0001` in order; the next number is the highest existing one plus one. Record a decision only when it is hard to reverse, surprising without context, and the result of a real trade-off. A record can be one paragraph that names the context, the choice, and the reason. The `domain-modeling` skill writes records in the format of its `ADR-FORMAT.md`.
