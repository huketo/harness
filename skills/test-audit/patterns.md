# Junk test patterns

The shared checklist for authoring and auditing. A new test matching one fails its gate unless it independently guards a contract from the [retention bar](SKILL.md#retention-bar); an audit hunts existing tests that match.

- **Coverage probes** — runs code without an assertion that could fail.
- **Tautologies** — compares a value with itself, or checks an identity copier.
- **Copied inventories** — fixtures, manifests, configuration values or export lists copied into the test, so any edit to the source forces the same edit to the test.
- **Source greps** — exact source, import or string searches standing in for runtime behavior.
- **Private call shapes** — private predicates or call sequences already proven at a real boundary.
- **Duplicate invocations** — the same contract exercised again with no distinct risk, including provider- or adapter-local replays of a shared helper.
- **Seam keepers** — tests whose only purpose is preserving a test-only export, global, flag, wrapper or injection hook; production code whose only callers are tests.
- **Self-produced oracles** — expected values generated by the helper, renderer or serializer under test.
- **Mock echoes** — a double that implements the asserted behavior, or one identical double standing in for different APIs.
- **Supplied outcomes** — fixtures that provide the receipt, admission or callback ordering the owner should produce, or persistence asserted against a store the path never writes.
- **Declared capabilities** — restating a capability flag instead of exercising the delivery or acknowledgement it promises.
- **Unreachable negatives** — a rejection that passes for an unrelated reason, such as another guard denying first or a branch production never reaches.
- **Overpromising names** — a name or fixture claiming more than the input exercises.

A test that breaks under a behavior-preserving refactor is asserting implementation; rewrite it at the owning boundary before it lands.
